## Windows ZIP path correction

The earlier ready ZIP used backslashes in entry names. Hostinger extracted these as literal filenames such as `assets\Accounts-....js`. Use `hostinger-realstate-linux.zip` instead. It is generated by `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-hostinger.ps1` after building. The script verifies the raw archive entries use forward slashes, without normalizing them during validation.

The supplied screenshots confirm the configured folder matches `public_html/realestateapp` and contains index.html. Nevertheless the public root, index.html and favicon.svg still return the provider 404. The asset path correction alone does not explain that root failure. Check hosting-plan IP versus DNS and ask Hostinger to verify the active virtual host and inherited rewrite rules if the destination is correct.
